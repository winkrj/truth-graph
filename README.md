# 심사 3분 전

사라진 데모 노트북을 찾기 위해 단서를 연결하고 보관함을 여는 짧은 웹 방탈출 게임입니다.

열 감지, 메시지 복원, 규정 조합, 동선 추적 퍼즐이 하나의 해결 과정으로 이어집니다. 잘못된 시도에도 진행 상황을 유지하고 힌트를 제공합니다.

## 현재 상태

핵심 플레이를 검토 중인 프로토타입입니다. 저장소의 현재 구현 상태는 [프로젝트 문맥](PROJECT_CONTEXT.md)에 기록돼 있습니다.

## 구성

- React · TypeScript · Vite
- 게임 상태 전이와 화면 표시를 분리한 구조
- Vitest를 통한 게임 로직 테스트

| 경로 | 역할 |
| --- | --- |
| `src/game/` | 상태 전이, 퍼즐 규칙, 화면에 공개할 정보 |
| `src/cases/` | 사건과 단서 정의 |
| `src/ui/` | 퍼즐 화면과 상호작용 |
| `tests/` | 게임 로직 검증 |

[게임 설계](GAME_DESIGN.md) · [프로젝트 문맥](PROJECT_CONTEXT.md)
