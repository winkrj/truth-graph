# 심사 3분 전

사라진 데모 노트북을 찾기 위해 단서를 연결하고 보관함을 여는 짧은 웹 방탈출 게임입니다.

책상 위 물건을 조사해 얻은 정보가 다음 퍼즐을 여는 단서가 됩니다. 열 감지와 메시지 복원으로 시작해 규정 조합과 동선 추적으로 이어지고, 세 개의 잠금을 풀면 보관함을 열 수 있습니다.

잘못된 답을 골라도 진행 상황은 유지됩니다. 막힌 퍼즐은 닫았다가 다시 살펴볼 수 있고, 잘못된 시도 후에는 힌트를 확인할 수 있습니다.

## 현재 상태

핵심 플레이가 이해하기 쉽고 재미있는지 사람의 피드백을 기다리는 프로토타입입니다. 자동 검사는 게임 규칙의 동작을 확인하며, 재미에 대한 판단은 플레이 테스트로 남겨둡니다. 현재 구현 범위는 [프로젝트 문맥](PROJECT_CONTEXT.md)에 기록돼 있습니다.

## 로컬 실행

Node.js `^20.19.0 || >=22.12.0`이 필요합니다. 저장소 루트에서 실행합니다.

```bash
npm install
npm run dev
```

개발 서버 주소는 실행 후 터미널에 표시됩니다. 게임 로직 테스트, 타입 검사, 빌드는 다음 명령으로 함께 확인할 수 있습니다.

```bash
npm run verify
```

## 구성

- React · TypeScript · Vite
- 게임 규칙을 계산하는 함수와 React 화면 표시를 분리한 구조
- 실행 중 AI 호출이나 네트워크 상태에 의존하지 않는 퍼즐 판정
- Vitest를 통한 게임 로직 테스트

| 경로 | 역할 |
| --- | --- |
| `src/game/` | 상태 전이, 퍼즐 규칙, 화면에 공개할 정보 |
| `src/cases/` | 사건과 단서 정의 |
| `src/ui/` | 퍼즐 화면과 상호작용 |
| `tests/` | 게임 로직 검증 |
